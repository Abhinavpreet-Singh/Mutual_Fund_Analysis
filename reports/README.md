# 📊 Reports Directory

This directory contains the generated charts, visual figures, text logs, and analytical reports generated throughout the sprint.

## 🗂️ Structure

- **`day3_charts/`**: Exploratory data analysis charts (16+ visual PNG/HTML figures covering NAV trends, AUM/SIP growth, demographic and sector allocation breakdowns).
- **`day4/`**: Fund performance statistics reports (CAGR reports, volatility/drawdown metrics, scorecard tables, and benchmark performance comparison plots).
- **`day6/`**: Advanced analytics and risk reports (historical Value at Risk (VaR), Conditional VaR (CVaR), rolling Sharpe ratio time series, cohort clustering, and sector concentration risk HHI).

## 📄 Key File Summaries

- **`data_ingestion_summary.txt`**: Logs rows, columns, and Null percentages for all raw CSV datasets during ingestion.
- **`data_cleaning_summary.txt`**: Summarizes the deduplication count and data validation adjustments made.
- **`day2_query_results.md`**: Text output and result tables of the 10 analytical SQL queries executed on the SQLite database.
- **`day3_findings.md`**: Bulleted summary of the 10 core business insights derived from EDA.
- **`day4/fund_scorecard.csv`**: Composite scores and rank listings for the mutual fund schemes.
- **`day6/var_cvar_report.csv`**: Downside risk VaR (95%) and CVaR (95%) metrics.
- **`day6/sector_hhi.csv`**: Herfindahl-Hirschman Index (HHI) concentration scores for equity funds.
- **`day6/sip_continuity.csv`**: Gaps and at-risk churn indicators for SIP investors.
